## Risks & test landmines (CLAUDE.md authoring rules every new test MUST obey)

1. **`set -euo pipefail` is armed** (`test.sh:6/16`, `claudecode-telegram.sh:6`). A bare `((x++))` returns 1 when x was 0 → aborts; a function whose last line is `cond && action` returns 1 when cond is false. Use `((++x))` or `((x++)) || true`; end branches explicitly. (The C3/N1/C6 production bugs ARE this landmine.)
2. **RED tests of lifecycle helpers must invoke them errexit-suppressed** (`if helper; then` / `helper || true`) and assert on side-effects + a captured sentinel — never run them bare, or the unpatched-base abort crashes the harness instead of showing a clean red.
3. **`run_test` only guards `test_*` bodies, NOT helpers called outside it.** KEEP `main`'s `"$test_name" || fail` form — F1 acceptance gate. Tests of `stop_single_node`/`cmd_clean`/`wait_for_*` must capture exit status, never call bare.
4. **Never shadow the global counters** `passed`/`failed`/`tests_run` with `local` (bash dynamic scoping swallows the suite-level count). Pick other names.
5. **Never inject multi-line bash syntax via send-keys into a tmux pane** — this box's `~/.bashrc` execs fish. Start receiver panes with `tmux new-session -d -s "$name" -x 200 -y 50 "/bin/sh -c 'your loop'"`. Do NOT use `/bin/bash` as the pane command. (e2e `spawn_real_claude` is safe — it routes through the bridge's C1 launch, not a raw pane.)
6. **Monkeypatch iron rule:** patch bridge module attributes (`bridge.X = ...`), never rebind imported copies. When faking `subprocess.run`, ALSO set `bridge.tmux_exists = lambda *a: False` or `create_session` bails "Worker already exists".
7. **`grep -c` prints 0 AND exits 1 on no-match** → under pipefail a `clean=$(grep -c ...)` aborts. Use `grep -cE ... 2>/dev/null || true; var=${var:-0}`.
8. **Time-window / launch-race tests must FORCE the branch under test** — keep a reproducing knob (`PANE_LAUNCH_CONFIRM_SECS=8`, or pointing fake-claude at the wrong thread) that makes the old behavior red.
9. **Opaque failures: instrument, don't guess** — stderr is suppressed and `cleanup()` deletes `$BRIDGE_LOG`. Temporarily redirect to `/tmp/dbg.err | tee /tmp/dbg.out`, side-copy the bridge log live, then revert with `git checkout -- test.sh`.
10. **C4-class trap:** gate `run_mock_tests` on `wait_for_port "$PORT"` (bridge actually listening), NOT on `MOCK_TG_ACTIVE`. `wait_for_port` must stay inside an `if` (errexit-suppressed). F3 self-gate protects non-P8 entry paths.
11. **Test behavior, not scaffolding** — assert the user-visible outcome at the WIRE (mock `/_recorded`) or that a pane is STILL ALIVE, not that an HTTP call returned OK. Every new test gets a sensitivity proof (the exact knob that makes it red). A `jq` filter that selects nothing passes vacuously — the Task 4 wire-shape sanity check guards this.
12. **PPID assertions on this box:** assert "PPID != launcher pgid", NOT "== 1" (subreaper/cgroup setups reparent to a subreaper PID, not literally 1).
13. **Known environmental flaky:** `test_send_to_session_integration` (three failure modes per CLAUDE.md). Run the FULL unfiltered suite + worktree control experiment before attributing a red to any v1.3.5 change.
